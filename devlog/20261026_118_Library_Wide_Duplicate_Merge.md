# 118 — 라이브러리 전체 중복 항목 병합, 같은 논문 PDF 사본 정리 (2026-10-26 ~ 27)

코드 변경은 없고 라이브 데이터 작업이다. [117](./20261023_117_Pending_OCR_And_PDF_Download_Guard.md) §5에서 새로 들어온 27편 안의 5쌍을 합친 뒤,
사용자 요청으로 라이브러리 전체의 같은 DOI·제목 묶음도 같은 방식으로 합쳤다. 이어서 한 항목에 같은 논문 PDF가 두 벌 이상 붙은 것을 정리했다(§8).

## 1. 대상

휴지통 밖에서 DOI(대소문자 무시)와 제목(영숫자·한글만 남겨 비교)이 같은 묶음이다.

- DOI 묶음 전체가 같은 제목인 것 136개(280편). 117 §5에서 "136묶음"이라고 한 것이다
- DOI 묶음 안에 제목이 다른 항목이 섞여 있지만, 같은 제목끼리 둘 이상인 것 4개(8편)
- 합계 140묶음 288편, 그중 3편 이상인 묶음은 7개

Zotero에서 각 항목과 그 자식(첨부·노트·주석)을 다시 읽었다. **노트 0, 주석(annotation) 0**이었다.
병합 대상 쪽 자식은 PDF 하나와 OCR JSON 하나뿐이었다. 링크 첨부(`linked_url`) 4개는 모두 남길 항목에 붙어 있었다.

## 2. 같은 DOI·제목이어도 같은 문서가 아닌 5묶음

DOI와 제목만 믿지 않고 PDF 내용을 대조했다. 중복 PDF마다 OCR 본문의 단어(영문 4자 이상)가 남길 항목 PDF 본문에 얼마나 들어 있는지(containment)를 쟀고, 쪽수도 비교했다.

| 결과 | PDF 수 |
|---|---|
| 남길 항목과 같은 해시 | 39 |
| containment ≥ 0.9 | 79 |
| 0.8 ~ 0.9 | 22 |
| 0.6 ~ 0.8 | 1 (한국어 논문 — 영단어만 세서 낮게 나온다, 같은 판본) |
| < 0.6 | 5 |
| 중복 쪽에 PDF 없음 | 2 |

0.6 미만인 PDF와, 쪽수가 크게 다른 PDF의 첫 쪽을 직접 읽었다. 다음 5묶음은 **중복이 아니어서 병합하지 않았다.**

| DOI | 항목 | 실제 내용 |
|---|---|---|
| `10.1098/rsbl.2004.0194` | 1746 / 1745 | 1746은 Electronic appendix(2쪽), 1745는 본문(6쪽) — 본문과 부록이 항목 둘로 나뉘었다 |
| `10.1038/s41559-020-01291-1` | 2315 / 2314 | 2315는 Supplementary information(10쪽), 2314는 본문(15쪽) — 위와 같은 경우 |
| `10.33063/diva-442412` | 1615 / 190 | 둘 다 메타데이터가 틀렸다. 1615는 Stein 2008, 190은 Kesidis 2020의 Uppsala 박사논문인데 둘 다 "Multiscale Modeling in Systems Biology"(Coulier 2021)로 되어 있다 |
| `10.18261/8200049639-1975` | 2440 / 538 / 2159 | Fossils and Strata 4의 서로 다른 챕터 셋. Miller pp. 155–178, Henningsmoen pp. 179–200, Fortey & Owens pp. 227–239가 모두 책 전체 레코드(`book`)로 들어 있다 |
| `10.1093/molbev/msae105` | 925 / 915 | 925는 Tel Aviv 대학 석사논문(42쪽)인데 MBE 논문 메타데이터가 붙었고, 915가 MBE 논문(14쪽)이다 |

containment는 "중복 PDF가 남길 PDF에 들어 있는가" 한 방향만 잰다. 그래서 남길 쪽 PDF가 더 큰 문서(molbev — 논문을 품은 학위논문)이면 0.83으로 통과해 버린다.
쪽수 비교를 함께 봐서 이 경우를 잡았다. 쪽수가 크게 다른 나머지 둘(Chopko 강 2쌍)은 중복 쪽 PDF가 1쪽짜리 조각이고 0.88~0.90이 포함돼 있어 병합했다.

## 3. 남길 항목 고르기

1. OCR된 PDF가 있는 항목
2. 그중 Zotero `dateAdded`가 가장 이른 항목 — Zotero "Merge Items"의 기본값과 같다
3. 같으면 다른 논문의 인용 연결(`Reference.resolved_paper`)이 많은 항목

예외는 하나다. `10.1007/s10739-017-9471-1`(Sterner & Lidgard 2018)은 옛 항목이 저널 필드 없는 `book`이어서 `journalArticle`인 4290을 남겼다.
PDF가 없는 중복 2편(205, 2481)은 같은 묶음의 PDF 있는 항목으로 합쳤다.
옛 항목의 `citationKey`는 대개 접미사가 없고 새 항목에 `…a`·`…b`가 붙어 있다. 인용 키를 쓰는 원고도 옛 항목을 가리키고 있을 가능성이 높다.

## 4. 병합

117 §5의 스크립트를 일반화했다. 묶음당 여러 항목을 처리하고, 412·429 응답은 재시도하며, 다시 돌리면 이미 된 것은 건너뛴다.

- **135묶음, 중복 142항목**을 남길 항목 쪽으로 합쳤다. 자식 280개(PDF 140, JSON 140)는 항목째 휴지통으로 보냈다(`PATCH {"deleted": 1}`)
- 남길 항목에 중복 항목의 컬렉션·태그를 더하고 `dc:replaces`에 중복 항목 URI를 달았다. 3편 묶음은 두 URI가 다 들어간다. Word 원고의 인용은 남길 항목으로 이어진다
- 남길 항목에서 비어 있던 필드만 채웠다: journalAbbreviation 31, language 30, url 16, abstractNote 7, issue 5, ISSN 3, volume 2, pages 1.
  `extra`·`date`는 건드리지 않았다(중복 쪽 `extra`에 엉뚱한 ISBN이 있는 등)
- **PDF는 옮기지 않았다.** 117 §5와 같은 이유다(한 Paper에 같은 논문 PDF가 둘이면 도판과 본문이 두 번 나온다). 필요하면 휴지통에서 복원할 수 있다
- 중복 쪽 자식이 노트나 링크라면 옮기고, 주석이 달린 PDF가 있으면 그 묶음을 멈추게 해 두었다. 해당하는 것은 없었다

## 5. 로컬 DB

- 다른 논문이 중복 항목을 인용하던 연결 830건을 남길 항목으로 옮겼다(`Reference.resolved_paper`). `CitedWork.merged_into_paper`도 3건 옮겼다
  - **왜 옮기나:** 나중에 Zotero 휴지통을 비우면 `purge_local_by_keys`가 `delete_instance(recursive=True, delete_nullable=True)`로 그 논문을 가리키는 nullable FK 행까지 지운다.
    옮기지 않으면 인용 연결이 사라진다. 117 §5는 `Reference`만 옮기고 `CitedWork`는 빠뜨렸으므로 그 5쌍도 이번에 같이 처리했다(3건에 포함)
- 중복 항목 자신의 references 11,253행을 지우고 `references_checked`를 해제했다. `normalize_works`·`citation_stats`가 휴지통 논문을 거르지 않기 때문이다
- 남길 항목은 Zotero에서 다시 읽어 필드·저자를 갱신하고, 중복 항목의 컬렉션을 PaperFolder에 더했다
- `sync_trash_state`가 논문 142·파일 280을 휴지통으로 표시했다(복원 0). `recompute_cite_counts()` 결과, 인용이 있는 CitedWork는 263,321개다

## 6. 확인

- 같은 DOI·제목 묶음은 §2의 5개만 남았다
- Zotero 표본 4묶음(3편 묶음 포함)을 다시 읽었다. 남길 항목은 휴지통 밖이고, 컬렉션이 합쳐졌고, `dc:replaces`가 있다. 중복 항목은 `deleted`이고, 남길 항목의 자식은 PDF·JSON 하나씩 그대로다
- 라이브러리(휴지통 제외): 논문 9,766, PDF 9,823, 도판 97,982, 대기 0, Info 검토 대기 5,066
- 휴지통 논문을 가리키는 references는 9행(인용하는 쪽 8, 인용되는 쪽 1)이다. 모두 10-22 정리 때 휴지통으로 간 2612·4142의 것이고, 이번 병합과는 무관하다

## 7. 남은 것

- **§2의 5묶음** — 병합이 아니라 고쳐야 할 것이다
  - 본문/부록 2쌍: 부록 PDF를 본문 항목 밑으로 옮기고 부록 항목을 휴지통으로 보내거나, 지금처럼 둔다
  - diva 2편, molbev 925: 메타데이터를 실제 학위논문으로 고친다
  - Fossils and Strata 4의 3편: 각 챕터의 `bookSection`으로 고친다
- **처리된 PDF가 둘 이상 붙은 논문 79편** — 이번 병합 전부터 있던 것이다(이번에는 PDF를 옮기지 않았다). 10-27에 정리했다(§8).
  처음에 파일 이름만 보고 "4479·5069도 같은 논문 두 벌"이라고 적었는데 틀렸다. 내용을 대조해 보니 둘 다 둘째 PDF가 다른 문서(2쪽·4쪽)였다
- 제목이 달라 이번 기준에 걸리지 않은 중복(제목 표기 차이, DOI 없는 항목)은 찾지 않았다

## 8. 같은 논문 PDF 두 벌 정리 (10-27)

사용자 요청: 같은 PDF가 둘씩 있으면 하나는 지운다.

### 8.1 대조

PDF(또는 이미지)가 둘 이상 붙은 논문 79편의 파일을 쌍마다 비교했다. 기준은 §2와 같은 단어 containment(양방향)와 쪽수다.

- 대부분은 본문 + 부록·보충자료·그림 파일이어서 **다른 문서**다. Animal biodiversity 2013 addendum(16개), Bayesian Data Analysis seminar(11개) 같은 묶음 자료도 있다
- 같은 문서로 본 것은 다음 셋이다
  - 해시가 같은 쌍 3개
  - 양방향 containment ≥ 0.8이고 쪽수 차이가 max(2쪽, 15%) 이하인 쌍
  - 경계라서 첫 쪽·끝 쪽을 읽어 정한 7쌍 — 같은 스캔에 도서관 대출 표지나 ResearchGate 표지가 붙은 것(412·4991), accepted manuscript/preprint와 출판본(2652·2746·2797), SYNTHESYS 핸드북과 같은 내용의 EJT 출판본(5077)
- 결과: **49편에서 53개**를 지울 PDF로 정했다. 2756은 같은 논문이 4벌(그중 2벌은 같은 해시), 2767은 3벌이었다.
  4482는 같은 PNG(차트 한 쪽)가 두 번 붙어 있었다
- 주석(annotation)이 달린 PDF는 2262 하나뿐이다. 거기 붙은 둘째 파일은 다른 문서여서 손대지 않았다

### 8.2 무엇을 남겼나

- 판본이 다른 4쌍은 **출판본**을 남겼다: 2652 → 3514, 2746 → 3621, 2797 → 3718, 5077 → 6642
- 나머지는 **본문 텍스트(passages)를 만든 파일**을 남겼다. 그래야 검색 결과의 쪽 번호가 남긴 PDF와 맞는다. 같으면 도판 처리가 더 된 쪽, 그다음은 Zotero에 먼저 들어온 쪽이다
- 손으로 고친 도판(`user_confirmed`·잠금)은 지울 쪽에 하나도 없었다

### 8.3 처리

- Zotero: 지울 PDF 53개와 그 OCR JSON 사이블링 50개를 휴지통으로 보냈다(사이블링은 파일 이름의 `.{hash[:8]}.json`으로 짝지었다). 남긴 PDF와 그 JSON은 그대로다
- 로컬: 그 PaperFile 행 103개를 지웠다. 휴지통 비우기(`purge_local_by_keys`)가 하는 일과 같다. **표시만 하지 않은 이유:** 앱의 `figures_for_paper()`와 `_primary_file()`은 PaperFile의 `trashed_at`을 보지 않는다.
  표시만 해 두면 지운 사본의 도판이 Figures 탭에 그대로 남는다. 도판 547개(FigureEntry·FigurePanel 포함)를 함께 지웠다
- 본문 텍스트가 지운 사본에서 나왔던 2746·2797은, 남긴 PDF의 OCR 캐시로 passages를 다시 만들었다(`_pages_from_raw` + `split_into_passages`, `process_paper_file`과 같은 방식).
  4482도 같은 처리를 거쳤지만 같은 PNG라 내용은 그대로다
- 확인: 103개 모두 Zotero 휴지통에 있고, 남긴 파일은 하나도 휴지통에 없다. Zotero 휴지통에 있는데 로컬에 살아 있는 PaperFile은 0이다. 짝 잃은 도판·항목·패널은 0이다.
  2746은 passages 11쪽(남긴 PDF 11쪽), 2797은 10쪽이다
- 라이브러리(휴지통 제외): PDF 9,770, 도판 97,435. PDF가 둘 이상 남은 논문 32편은 서로 다른 문서다

### 8.4 남은 것

- **앱이 휴지통 첨부를 숨기지 않는다** — `figures_for_paper()`·`_primary_file()`(그리고 그 둘을 쓰는 곳)이 `PaperFile.trashed_at`을 거르지 않는다. 지금까지는 항목째 휴지통으로 가는 경우만 있어 드러나지 않았다
- **4482(Geyer 2020)의 passages는 11쪽 PDF가 아니라 1쪽 PNG에서 나왔다**(이번 정리 전부터). passages는 논문당 하나이고 마지막으로 OCR한 파일이 덮어쓴다.
  그래서 본문 PDF가 검색에 안 잡힌다. 남은 32편 중에도 부록이 본문을 덮어쓴 경우가 있을 수 있다
